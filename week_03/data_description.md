# 数据集说明
## 数据来源
本数据集为英文短信数据集`sms_data.csv`，用于垃圾短信二分类实验，样本为真实手机短信片段。

## 字段与标签含义
数据集共两列：`label`为分类标签，`text`为短信原文。
- label：`ham`代表正常普通短信；`spam`代表垃圾广告、诈骗促销短信，是模型需要预测的目标标签。
- text：短信原始文本，是模型输入，每条记录对应一条短信样本。

## 数据规模
数据集共111条短信样本，2个字段。数据集类别分布不均衡，ham正常短信样本数量远多于spam垃圾短信。垃圾短信普遍较长，包含大量电话号码、奖金、订阅推广内容；正常短信长短差异大，包含口语缩写、网络简写。文本长度分布可以参考生成的`text_len_hist.png`，类别分布见`class_dist.png`。

## 发现的数据问题
1. 文本存在HTML转义字符如`&amp;`、`&lt;#&gt;`，属于脏字符，会干扰文本处理。
2. 存在重复样本，同一条callertune短信出现两次。
3. 部分短信包含特殊符号、乱码字符，还有极短口语化文本，有效语义较少。
4. 类别不平衡，spam样本数量偏少，直接训练会造成模型偏向预测ham。

以上问题需要在后续数据清洗阶段进行处理，否则会影响分类模型效果。
